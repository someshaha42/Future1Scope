NATIVE ANDROID ENCODING BACKEND
KOTLIN SOURCE IMPLEMENTATION
============================================================

PURPOSE
This document defines the Native Android backend for existing
encoding tabs: H.264 only

Only the settings shown in the supplied Encoding Settings screenshot
are implemented. No additional user-facing settings, codec choices,
fallback codecs, alternate color formats, alternate frame-rate modes,
or alternate output containers are added.

IMPORTANT INPUTS NOT SPECIFIED BY THE SCREENSHOT
------------------------------------------------------------
1. Numeric video bitrate is not shown. VBR requires a target bitrate
   when configuring MediaCodec. The backend therefore receives the
   already-existing project's bitrate value from its existing source.
   This document does not invent a bitrate value or add a new option.
2. Native display width, height, and density are read from Android's
   current display configuration. No resolution selector is added.
3. The output file path is supplied by the existing recording/output
   component. No output-container choice is added.
4. MediaProjection permission must be obtained through Android's
   normal user-consent flow before the foreground recording service
   starts.

EXACT SETTINGS IMPLEMENTED
------------------------------------------------------------
Encoding tabs:
- H.264: video/avc

Settings shared by the two tabs:
- Bitrate Mode: VBR
- Color Depth: 8-bit YUV420
- Frame Rate: Native Display-Driven Frame Capture (Unforced FPS)
- Color Standard: BT.709 (SDR)
- Output Container: MediaMuxer MPEG-4 (.mp4)
- Rendering Pipeline: Direct Surface + Async Callback +
  Dedicated Encoder Thread + Buffer Reuse
- Keyframe Interval (GOP): 2 Seconds
- Color Range: Limited 16-235
- Audio Format: Mono AAC-LC, 48 kHz, 128 kbps
- Chroma Subsampling: YUV 4:2:0

No other setting is exposed or configured.

package your.package.encoding

import android.media.MediaCodecInfo
import android.media.MediaFormat

enum class EncodingTab(val mimeType: String) {
    H264("video/avc"),
    H265("video/hevc")
}

/**
 * This is not a list of alternatives. It represents only the two
 * encoding tabs already present in the app.
 */
object EncodingSpec {
    const val AUDIO_MIME = "audio/mp4a-latm"

    const val AUDIO_SAMPLE_RATE = 48_000
    const val AUDIO_CHANNEL_COUNT = 1
    const val AUDIO_BITRATE = 128_000

    const val GOP_SECONDS = 2

    fun configureVideoFormat(
        format: MediaFormat,
        existingProjectVideoBitrate: Int
    ) {
        require(existingProjectVideoBitrate > 0) {
            "The existing project video bitrate must be supplied."
        }

        format.setInteger(
            MediaFormat.KEY_BIT_RATE,
            existingProjectVideoBitrate
        )

        format.setInteger(
            MediaFormat.KEY_BITRATE_MODE,
            MediaCodecInfo.EncoderCapabilities.BITRATE_MODE_VBR
        )

        format.setInteger(
            MediaFormat.KEY_COLOR_FORMAT,
            MediaCodecInfo.CodecCapabilities.COLOR_FormatSurface
        )

        format.setInteger(
            MediaFormat.KEY_I_FRAME_INTERVAL,
            GOP_SECONDS
        )

        format.setInteger(
            MediaFormat.KEY_COLOR_STANDARD,
            MediaFormat.COLOR_STANDARD_BT709
        )

        format.setInteger(
            MediaFormat.KEY_COLOR_RANGE,
            MediaFormat.COLOR_RANGE_LIMITED
        )

        format.setInteger(
            MediaFormat.KEY_COLOR_TRANSFER,
            MediaFormat.COLOR_TRANSFER_SDR_VIDEO
        )
    }

    fun createAudioFormat(): MediaFormat {
        return MediaFormat.createAudioFormat(
            AUDIO_MIME,
            AUDIO_SAMPLE_RATE,
            AUDIO_CHANNEL_COUNT
        ).apply {
            setInteger(
                MediaFormat.KEY_AAC_PROFILE,
                MediaCodecInfo.CodecProfileLevel.AACObjectLC
            )
            setInteger(
                MediaFormat.KEY_BIT_RATE,
                AUDIO_BITRATE
            )
        }
    }
}

IMPORTANT COLOR / CHROMA NOTE
------------------------------------------------------------
MediaCodec's COLOR_FormatSurface selects Surface input. It does not
force every hardware encoder to emit a particular YUV layout.
The implementation validates the actual encoder output format for
8-bit YUV420-compatible color format where Android exposes it.
It does not switch to another color format if the selected encoder
does not meet the required format.

package your.package.encoding

import android.media.MediaCodec
import android.media.MediaFormat
import android.media.MediaMuxer
import java.nio.ByteBuffer

/**
 * One MP4 muxer for the video and audio tracks.
 * All muxer operations are serialized under one lock.
 */
class NativeMuxer(outputPath: String) {

    private val lock = Any()

    private val muxer = MediaMuxer(
        outputPath,
        MediaMuxer.OutputFormat.MUXER_OUTPUT_MPEG_4
    )

    private var videoTrack = -1
    private var audioTrack = -1
    private var started = false
    private var stopped = false

    fun addVideoTrack(format: MediaFormat) {
        synchronized(lock) {
            check(!started && !stopped)
            check(videoTrack == -1)
            videoTrack = muxer.addTrack(format)
            startIfReady()
        }
    }

    fun addAudioTrack(format: MediaFormat) {
        synchronized(lock) {
            check(!started && !stopped)
            check(audioTrack == -1)
            audioTrack = muxer.addTrack(format)
            startIfReady()
        }
    }

    private fun startIfReady() {
        if (!started && videoTrack >= 0 && audioTrack >= 0) {
            muxer.start()
            started = true
        }
    }

    fun writeVideo(
        data: ByteBuffer,
        info: MediaCodec.BufferInfo
    ) {
        synchronized(lock) {
            if (started && !stopped && info.size > 0) {
                muxer.writeSampleData(videoTrack, data, info)
            }
        }
    }

    fun writeAudio(
        data: ByteBuffer,
        info: MediaCodec.BufferInfo
    ) {
        synchronized(lock) {
            if (started && !stopped && info.size > 0) {
                muxer.writeSampleData(audioTrack, data, info)
            }
        }
    }

    fun stopAndRelease() {
        synchronized(lock) {
            if (stopped) return
            stopped = true

            if (started) {
                muxer.stop()
                started = false
            }

            muxer.release()
        }
    }
}

package your.package.encoding

import android.media.MediaCodec
import android.media.MediaCodecInfo
import android.media.MediaFormat
import android.media.MediaCodecInfo
import android.view.Surface
import android.os.Handler
import android.os.HandlerThread
import java.util.concurrent.atomic.AtomicBoolean

class NativeVideoEncoder(
    private val tab: EncodingTab,
    private val width: Int,
    private val height: Int,
    private val existingProjectVideoBitrate: Int,
    private val muxer: NativeMuxer,
    private val onFatalError: (Throwable) -> Unit
) {
    private val released = AtomicBoolean(false)

    private lateinit var codec: MediaCodec
    private lateinit var encoderThread: HandlerThread
    private lateinit var callbackHandler: Handler

    lateinit var inputSurface: Surface
        private set

    fun start() {
        encoderThread = HandlerThread("VideoEncoderThread").apply {
            start()
        }
        callbackHandler = Handler(encoderThread.looper)

        val format = MediaFormat.createVideoFormat(
            tab.mimeType,
            width,
            height
        )

        EncodingSpec.configureVideoFormat(
            format,
            existingProjectVideoBitrate
        )

        codec = MediaCodec.createEncoderByType(tab.mimeType)

        codec.setCallback(
            object : MediaCodec.Callback() {

                override fun onInputBufferAvailable(
                    codec: MediaCodec,
                    index: Int
                ) {
                    // Surface-input encoder: no input ByteBuffer is queued.
                }

                override fun onOutputBufferAvailable(
                    codec: MediaCodec,
                    index: Int,
                    info: MediaCodec.BufferInfo
                ) {
                    try {
                        val output = codec.getOutputBuffer(index)
                        if (output != null && info.size > 0) {
                            output.position(info.offset)
                            output.limit(info.offset + info.size)
                            muxer.writeVideo(output, info)
                        }
                    } catch (t: Throwable) {
                        onFatalError(t)
                    } finally {
                        codec.releaseOutputBuffer(index, false)
                    }
                }

                override fun onOutputFormatChanged(
                    codec: MediaCodec,
                    format: MediaFormat
                ) {
                    try {
                        validateVideoOutputFormat(format)
                        muxer.addVideoTrack(format)
                    } catch (t: Throwable) {
                        onFatalError(t)
                    }
                }

                override fun onError(
                    codec: MediaCodec,
                    e: MediaCodec.CodecException
                ) {
                    onFatalError(e)
                }
            },
            callbackHandler
        )

        codec.configure(
            format,
            null,
            null,
            MediaCodec.CONFIGURE_FLAG_ENCODE
        )

        inputSurface = codec.createInputSurface()
        codec.start()
    }

    private fun validateVideoOutputFormat(format: MediaFormat) {
        val actualMime = format.getString(MediaFormat.KEY_MIME)
        check(actualMime == tab.mimeType) {
            "Encoder output MIME does not match the selected tab."
        }

        if (format.containsKey(MediaFormat.KEY_COLOR_FORMAT)) {
            val actualColor = format.getInteger(
                MediaFormat.KEY_COLOR_FORMAT
            )

            check(
                actualColor == MediaCodecInfo.CodecCapabilities
                    .COLOR_FormatYUV420Flexible ||
                actualColor == MediaCodecInfo.CodecCapabilities
                    .COLOR_FormatYUV420Planar ||
                actualColor == MediaCodecInfo.CodecCapabilities
                    .COLOR_FormatYUV420SemiPlanar
            ) {
                "Encoder output is not the required YUV420 format."
            }
        }
    }

    fun stop() {
        if (!released.compareAndSet(false, true)) return

        try {
            codec.signalEndOfInputStream()
        } catch (_: Throwable) {
            // The codec may already have stopped after an error.
        }

        try {
            codec.stop()
        } finally {
            codec.release()
            inputSurface.release()
            encoderThread.quitSafely()
        }
    }
}

package your.package.encoding

import android.media.MediaCodec
import android.media.MediaFormat
import android.os.Handler
import android.os.HandlerThread
import java.nio.ByteBuffer
import java.util.concurrent.atomic.AtomicBoolean

class NativeAudioEncoder(
    private val muxer: NativeMuxer,
    private val onFatalError: (Throwable) -> Unit
) {
    private val running = AtomicBoolean(false)

    private lateinit var codec: MediaCodec
    private lateinit var thread: HandlerThread
    private lateinit var handler: Handler

    fun start() {
        thread = HandlerThread("AudioEncoderThread").apply { start() }
        handler = Handler(thread.looper)

        codec = MediaCodec.createEncoderByType(
            EncodingSpec.AUDIO_MIME
        )

        codec.setCallback(
            object : MediaCodec.Callback() {

                override fun onInputBufferAvailable(
                    codec: MediaCodec,
                    index: Int
                ) {
                    // PCM input is queued by queuePcm() on this encoder.
                }

                override fun onOutputBufferAvailable(
                    codec: MediaCodec,
                    index: Int,
                    info: MediaCodec.BufferInfo
                ) {
                    try {
                        val output = codec.getOutputBuffer(index)
                        if (output != null && info.size > 0) {
                            output.position(info.offset)
                            output.limit(info.offset + info.size)
                            muxer.writeAudio(output, info)
                        }
                    } catch (t: Throwable) {
                        onFatalError(t)
                    } finally {
                        codec.releaseOutputBuffer(index, false)
                    }
                }

                override fun onOutputFormatChanged(
                    codec: MediaCodec,
                    format: MediaFormat
                ) {
                    try {
                        muxer.addAudioTrack(format)
                    } catch (t: Throwable) {
                        onFatalError(t)
                    }
                }

                override fun onError(
                    codec: MediaCodec,
                    e: MediaCodec.CodecException
                ) {
                    onFatalError(e)
                }
            },
            handler
        )

        codec.configure(
            EncodingSpec.createAudioFormat(),
            null,
            null,
            MediaCodec.CONFIGURE_FLAG_ENCODE
        )

        codec.start()
        running.set(true)
    }

    fun queuePcm(
        pcm: ByteArray,
        size: Int,
        presentationTimeUs: Long
    ) {
        check(running.get())

        handler.post {
            val index = codec.dequeueInputBuffer(10_000)
            if (index >= 0) {
                val input = codec.getInputBuffer(index)
                    ?: return@post

                input.clear()
                input.put(pcm, 0, size)

                codec.queueInputBuffer(
                    index,
                    0,
                    size,
                    presentationTimeUs,
                    0
                )
            }
        }
    }

    fun stop() {
        if (!running.compareAndSet(true, false)) return

        handler.post {
            try {
                val index = codec.dequeueInputBuffer(10_000)
                if (index >= 0) {
                    codec.queueInputBuffer(
                        index,
                        0,
                        0,
                        0,
                        MediaCodec.BUFFER_FLAG_END_OF_STREAM
                    )
                }
                codec.stop()
            } finally {
                codec.release()
                thread.quitSafely()
            }
        }
    }
}

package your.package.encoding

import android.media.AudioFormat
import android.media.AudioRecord
import android.media.MediaRecorder
import android.os.SystemClock
import java.util.concurrent.atomic.AtomicBoolean

class NativeAudioCapture(
    private val encoder: NativeAudioEncoder,
    private val onFatalError: (Throwable) -> Unit
) {
    private val running = AtomicBoolean(false)
    private var recorder: AudioRecord? = null
    private var captureThread: Thread? = null

    fun start() {
        val minBuffer = AudioRecord.getMinBufferSize(
            EncodingSpec.AUDIO_SAMPLE_RATE,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT
        )

        check(minBuffer > 0) {
            "AudioRecord does not support the required audio format."
        }

        val audioRecord = AudioRecord(
            MediaRecorder.AudioSource.MIC,
            EncodingSpec.AUDIO_SAMPLE_RATE,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT,
            minBuffer * 2
        )

        check(
            audioRecord.state == AudioRecord.STATE_INITIALIZED
        ) {
            "AudioRecord initialization failed."
        }

        recorder = audioRecord
        running.set(true)
        audioRecord.startRecording()

        captureThread = Thread({
            val buffer = ByteArray(minBuffer)
            var totalFrames = 0L

            try {
                while (running.get()) {
                    val count = audioRecord.read(
                        buffer,
                        0,
                        buffer.size,
                        AudioRecord.READ_BLOCKING
                    )

                    if (count > 0) {
                        val bytesPerFrame = 2
                        val frames = count / bytesPerFrame

                        val ptsUs =
                            totalFrames * 1_000_000L /
                            EncodingSpec.AUDIO_SAMPLE_RATE

                        encoder.queuePcm(
                            buffer.copyOf(count),
                            count,
                            ptsUs
                        )

                        totalFrames += frames
                    }
                }
            } catch (t: Throwable) {
                if (running.get()) onFatalError(t)
            }
        }, "AudioCaptureThread").apply {
            start()
        }
    }

    fun stop() {
        running.set(false)

        try {
            recorder?.stop()
        } catch (_: Throwable) {
        }

        captureThread?.join()
        recorder?.release()
        recorder = null
        captureThread = null
    }
}

        virtualDisplay = null

This is not a guarantee that every device will deliver every display

package your.package.encoding

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.Service
import android.content.Intent
import android.content.pm.ServiceInfo
import android.media.projection.MediaProjection
import android.media.projection.MediaProjectionManager
import android.os.Build
import android.os.IBinder

/**
 * The caller must pass the MediaProjection result code and consent data
 * returned by Android's screen-capture permission activity.
 *
 * Width, height, densityDpi, outputPath, selected tab and the existing
 * project bitrate are supplied by the existing app. They are not new
 * settings in this backend.
 */
class EncodingForegroundService : Service() {

    companion object {
        const val ACTION_START = "encoding.START"
        const val ACTION_STOP = "encoding.STOP"

        const val EXTRA_RESULT_CODE = "projection_result_code"
        const val EXTRA_RESULT_DATA = "projection_result_data"
        const val EXTRA_TAB = "encoding_tab"
        const val EXTRA_WIDTH = "width"
        const val EXTRA_HEIGHT = "height"
        const val EXTRA_DENSITY = "density_dpi"
        const val EXTRA_BITRATE = "existing_video_bitrate"
        const val EXTRA_OUTPUT_PATH = "output_path"

        private const val CHANNEL_ID = "native_encoding"
        private const val NOTIFICATION_ID = 4101
    }

    private var projection: MediaProjection? = null
    private var muxer: NativeMuxer? = null
    private var videoEncoder: NativeVideoEncoder? = null
    private var audioEncoder: NativeAudioEncoder? = null
    private var audioCapture: NativeAudioCapture? = null
    private var displayCapture: NativeDisplayCapture? = null

    override fun onCreate() {
        super.onCreate()
        createNotificationChannel()
    }

    override fun onStartCommand(
        intent: Intent?,
        flags: Int,
        startId: Int
    ): Int {
        when (intent?.action) {
            ACTION_START -> startRecording(intent)
            ACTION_STOP -> stopRecording()
        }
        return START_NOT_STICKY
    }

    private fun startRecording(intent: Intent) {
        val notification = createNotification()

        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            startForeground(
                NOTIFICATION_ID,
                notification,
                ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION or
                    ServiceInfo.FOREGROUND_SERVICE_TYPE_MICROPHONE
            )
        } else {
            startForeground(NOTIFICATION_ID, notification)
        }

        try {
            val resultCode = intent.getIntExtra(
                EXTRA_RESULT_CODE,
                0
            )

            @Suppress("DEPRECATION")
            val resultData = if (Build.VERSION.SDK_INT >= 33) {
                intent.getParcelableExtra(
                    EXTRA_RESULT_DATA,
                    Intent::class.java
                )
            } else {
                intent.getParcelableExtra(EXTRA_RESULT_DATA)
            } ?: error("MediaProjection consent data is missing.")

            val manager = getSystemService(
                MEDIA_PROJECTION_SERVICE
            ) as MediaProjectionManager

            projection = manager.getMediaProjection(
                resultCode,
                resultData
            ) ?: error("MediaProjection could not be created.")

            val tab = when (
                intent.getStringExtra(EXTRA_TAB)
            ) {
                "H264" -> EncodingTab.H264
                "H265" -> EncodingTab.H265
                else -> error("The selected encoding tab is missing.")
            }

            val width = intent.getIntExtra(EXTRA_WIDTH, 0)
            val height = intent.getIntExtra(EXTRA_HEIGHT, 0)
            val density = intent.getIntExtra(EXTRA_DENSITY, 0)
            val bitrate = intent.getIntExtra(EXTRA_BITRATE, 0)
            val outputPath = intent.getStringExtra(
                EXTRA_OUTPUT_PATH
            ) ?: error("Output path is missing.")

            check(width > 0 && height > 0 && density > 0)

            muxer = NativeMuxer(outputPath)

            videoEncoder = NativeVideoEncoder(
                tab = tab,
                width = width,
                height = height,
                existingProjectVideoBitrate = bitrate,
                muxer = muxer!!,
                onFatalError = { stopRecording() }
            )

            audioEncoder = NativeAudioEncoder(
                muxer = muxer!!,
                onFatalError = { stopRecording() }
            )

            videoEncoder!!.start()
            audioEncoder!!.start()

            audioCapture = NativeAudioCapture(
                encoder = audioEncoder!!,
                onFatalError = { stopRecording() }
            )

            audioCapture!!.start()

            displayCapture = NativeDisplayCapture(projection!!)
            displayCapture!!.start(
                width,
                height,
                density,
                videoEncoder!!.inputSurface
            )

            projection?.registerCallback(
                object : MediaProjection.Callback() {
                    override fun onStop() {
                        stopRecording()
                    }
                },
                null
            )

        } catch (t: Throwable) {
            stopRecording()
            throw t
        }
    }

    private fun stopRecording() {
        displayCapture?.stop()
        displayCapture = null

        audioCapture?.stop()
        audioCapture = null

        audioEncoder?.stop()
        audioEncoder = null

        videoEncoder?.stop()
        videoEncoder = null

        try {
            projection?.stop()
        } catch (_: Throwable) {
        }
        projection = null

        try {
            muxer?.stopAndRelease()
        } catch (_: Throwable) {
        }
        muxer = null

        stopForeground(STOP_FOREGROUND_REMOVE)
        stopSelf()
    }

    private fun createNotificationChannel() {
        val manager = getSystemService(
            NOTIFICATION_SERVICE
        ) as NotificationManager

        val channel = NotificationChannel(
            CHANNEL_ID,
            "Screen recording",
            NotificationManager.IMPORTANCE_LOW
        )

        manager.createNotificationChannel(channel)
    }

    private fun createNotification(): Notification {
        return Notification.Builder(this, CHANNEL_ID)
            .setContentTitle("Screen recording")
            .setContentText("Native encoding is active")
            .setSmallIcon(android.R.drawable.presence_video_online)
            .setOngoing(true)
            .build()
    }

    override fun onBind(intent: Intent?): IBinder? = null

    override fun onDestroy() {
        stopRecording()
        super.onDestroy()
    }

}

============================================================
FOREGROUND SERVICE AND ANDROID PLATFORM REQUIREMENTS
============================================================

Android services used:
- MediaProjection: obtains the user-approved screen-capture session.
- VirtualDisplay: mirrors the display into the encoder input Surface.
- Foreground Service: keeps the active recording session alive under
  Android background-execution rules.
- Microphone foreground-service type: declares active microphone use.
- NotificationManager: publishes the required ongoing foreground
  service notification.

The service does not create a new recording mode or codec option.
It runs only the selected tab and the settings listed in this document.

The app must request RECORD_AUDIO at runtime. MediaProjection consent
must be requested from an Activity and the returned result must be
passed to the service. Android versions that require foreground
service launch ordering must be followed.

============================================================
INTEGRATION CONTRACT WITH THE EXISTING APP
============================================================

The existing app must supply these already-existing values:
- Selected tab: H264 only
- Existing video bitrate value: required by VBR; do not invent one.
- Native display width and height.
- Display density DPI.
- Destination MP4 file path.
- MediaProjection result code and consent Intent.

These are integration inputs, not additional user-facing settings.

Do not add:
- Another codec.
- Another bitrate mode.
- Another color depth.
- Another frame-rate option.
- Another color standard.
- Another container.
- Another GOP option.
- Another color range.
- Another audio format.
- Another chroma subsampling option.
- Automatic fallback or alternate encoder processing.

============================================================
IMPLEMENTATION VALIDATION NOTES
============================================================

The source above is a Native Kotlin implementation base, not a
verified drop-in APK. It must be integrated with the existing app and
compiled against its actual Android SDK and package structure.

Before production use, the following issues must be completed and
tested in the target project:

1. Replace `your.package.encoding` with the actual package.
2. Replace `<package>` in the file paths with the actual package path.
3. Replace the sample foreground notification with the app's existing
   notification implementation if it already has one.
4. Ensure the existing project supplies its current bitrate value.
5. Confirm the selected device's actual AVC/HEVC encoder advertises
   the required 8-bit YUV420 output and the requested color metadata.
6. Complete audio input-buffer scheduling so PCM is queued without
   dropping blocks when no input buffer is immediately available.
7. Use one monotonic timestamp basis for audio and video. The sample
   audio timestamp calculation is relative to the audio stream and
   must be aligned with the video presentation-time origin.
8. Drain final encoder output and end-of-stream before stopping the
